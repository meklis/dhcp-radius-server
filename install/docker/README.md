### Запуск dhcp-radius-server в docker за допомогою docker-compose    

0. Встановіть docker і docker-compose 
1. Скопіюйте вміст цього каталогу на кінцеву машину
2. Виправте файл .env-example і перейменуйте на .env
3. можна запускати - ```docker-compose up -d```

При необхідності внести зміни в конфігурацію (опис параметрів в конфізі) і виконати команду ```docker-compose up -d --build```
